# AutoProv — AI Automation Portfolio

A static portfolio website showcasing AI automation and n8n workflow projects.

## Projects
- AI Business Inbox
- 24/7 AI Messenger Customer Support Agent
- Receipt → Inventory Automation

## Tech
HTML, CSS, n8n, AI/LLM workflows, APIs, webhooks, Google Sheets, Meta Messenger, Google Vision, Loyverse.

## GitHub Pages
Upload all website files to the repository root, then enable:
**Settings → Pages → Deploy from a branch → main → /(root)**

Replace the placeholder contact email in `index.html` before publishing.
